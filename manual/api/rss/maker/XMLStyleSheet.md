maker.xml_stylesheet.new_xml_stylesheetで作成されたオブジェクトとします。

hrefとtypeは必ず指定する必要があります。ただし、
hrefに設定した値の拡張子が.xslまたは.cssの場合は
typeを指定する必要はありません。自動で推測します。
